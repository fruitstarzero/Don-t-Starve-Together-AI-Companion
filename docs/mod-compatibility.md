依据当前已安装游戏 756039、Workshop 源码和实际组件。运行时从 KnownModIndex 获取启用清单，配方取当前 AllRecipes／builder，观察限定为同伴附近；不会扫描整张地图或执行下载的代码。

附近主人 `performaction` 发生时，只登记实际 BufferedAction 的成功／失败回调；成功后才提供 owner_action_success，不能仅凭看见动作开始就声称学会或完成。操作方法由模型判断是否值得保存为 procedure／experience，可按后续证据修正。当前没有为新模组自动下载或执行控制脚本。
