## 转成指南的目标框架

这是研究后的设计建议，不是声称已经安装的功能。每个项目都应保存目标、证据、当前方法、下一检查条件和可恢复的中断点。

| 能力阶段 | 进入条件 | 完成证据 | 持续维护与退路 |
|---|---|---|---|
| 活下来并能返程 | 任意新世界/新会话/风险突变 | 当前能避黑、能吃、能撤退；知道主人和安全落脚点；工具够用 | 当场危险优先中断；返程路径不安全则转临时营地，恢复后继续原项目。 |
| 侦察与基地选址 | 生存余量允许外出 | 实际见过资源、危险和路线；确认基地及可用设施 | 标记已观察时间、地表/洞穴与可达性；旧点失效重新核查，不凭攻略生成不存在的资源坐标。 |
| 建成最小可持续生活 | 已选落脚点 | 原生设施确实落地、能使用；有做饭/燃料/存放/防护方法 | 缺炭、丝、金、齿轮按依赖拆解；没有必要时不重复造已有设施。 |
| 食物、木材与日用资源再生 | 基础设施可用 | 连续一轮获取—使用—补种/留种—回访能完成；库存覆盖生存和下一任务 | 普通食物先消耗临期；冬停长、巢耗空、农田缺水分开处理；优先稳定产出，不先强求巨型作物。 |
| 当前季节安全与下季准备 | 查看真实季节/温度/湿度和储备 | 保暖/防雨/降温方案实际可用，关键物料有着落；危险来袭有基地外退路 | 冬季依赖热与食物替代；春季补防雨防雷及夏季资源；夏季防热与基地焖烧；秋季恢复、补植与下一循环。 |
| 有条件的扩张 | 一段时间内生活稳定、紧急维护清空 | 当前科技、装备、补给和返程方案支持一个明确探索/战斗项目 | 首领、航海、遗迹等不是每日必做；缺执行能力或风险过高时求助，记录具体缺口，不能无休止失败。 |

### 温蒂与两条关键资源链

- 木炭：需求由锅/晾肉等项目产生 → 先查背包与箱子 → 找已烧毁可回收树 → 如需主动产炭，选真实检查过的隔离地块和可产炭树 → 点火并远离 → 确认燃烧结束 → 原生砍伐 → 捡炭 → 核对数量 → 继续原项目。安全条件不成立就另寻方法或向玩家说明，不在基地点火。
- 蜘蛛：需求由丝/腺体/食谱产生 → 观察巢等级、数量、阿比盖尔状态、装备和退路 → 有限引出、战斗 → 按实际掉落捡取 → 缺丝继续有限轮次或回访其他已知巢 → 完成后保留补充来源。群战优势不保证首领安全；阿比盖尔受伤/被击败、夜晚返程、库存已足会改变下一步。
- 这两条链必须通过原版动作和实际回执验收；本笔记没有据此声称现有同伴已支持点火、刷巢、所有技能或全部路线。

## 不应写死的项目

- 开局季节、季节长度、事件时间、资源数量、首领强度、掉落与模组配方。
- 温蒂全部技能默认已解锁，或从历史官方预告直接照搬战斗数值。
- 固定“第几天必须完成某物”“所有农务冬天停长”“洞穴绝对安全”。
- 记住地名即等于知道路线，或记忆中的箱子库存即等于现在库存。
- 成功发出动作等于动作完成；语言说“已经做好”不能替代物品/实体/数量变化。
- 让模型实时控制每帧：游戏继续流逝，模型存在时延。后续设计需要高频原生感知和执行、模型持续负责目标与方法、完成与异常触发重规划，以及持久目标记忆；具体调度频率需按实测调整。

## 后续适配最小证据链

一次任务可按“看到什么 → 为什么做 → 原生动作 → 回执 → 世界变化 → 下一步”记录。每条观察带游戏时间与位置；把已完成事实、待办计划、失败经验、攻略知识分开。行动期间仅持续附加必要事件；世界回滚、跨分片和会话切换继续遵守现有时间线边界。原型验收先做锅缺炭、冬帽缺丝、冬季食物替代、农田回访四条完整链，再扩大范围。
