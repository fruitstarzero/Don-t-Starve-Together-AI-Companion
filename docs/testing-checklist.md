# 首次游玩验收清单

先用新测试世界，尽量只启用本模组。以下是人工验收，自动化通过不替代你电脑上的结果。

1. 安装脚本找到正确游戏目录；生成随机本机配置。启动后桥接正常，F10面板可打开、中文输入清晰。
2. 生成温蒂同伴，检查背包和生存状态；设置基地后移动，再让她回基地，确认不把玩家新位置当作家。
3. 跟随、待命、地表集合传送、恢复原任务均正常。阿比盖尔召唤／收回使用真实机制。
4. 安排少量采集／制作目标，确认消耗真实材料、实际取得物品；聊天问攻略不会清空目标。
5. 任务中临时跟随／避险，再恢复，检查阶段与已完成数量。受阻时有明确原因，不能反复声称完成。
6. 缺料制作时，先查箱子、按缺额取部分物品，再补中间材料／科技。仓满时按需补箱；玩家背包不当作公共库存。
7. 打开“目标／物资”，观察眼前／中期／长期目标与下一步。自主行动3～5分钟，检查是否围绕真实缺口推进；模型慢时不应反复重置任务。
8. 观察主动分享、缺料吐槽与具体求助：能说也能保持沉默，不能连续刷屏。
9. 左下角历史窗能完整滚动查看，按钮不误触移动；检查白天、夜晚、固定黑字／白字、收起。
10. 保存退出并重进，检查基地、任务、目标板与照料项目；换测试世界不能继承前一局的实际库存。
11. 停止AI桥接后不能冒充模型在线，快捷控制仍可用；重启桥接后恢复连接。离线安排不能在下次擅自补跑。
12. 最后再逐个加入常用模组。若新模组只提供专属GUI或新动作，先作为未知能力处理。

反馈时提供版本、游戏版本、简短步骤和脱敏错误；不要上传state、角色、配置、存档或完整日志。
