# 饥荒联机版 AI 伙伴

让一个使用原版温蒂玩家实体的 AI 同伴，在你自建的《饥荒联机版》世界里生活、做事和交流。她有自己的背包与生存需求，可以跟随帮忙，也可以按当前目标自主行动；你通过 F10 面板远程聊天、安排任务或把她叫到身边。

**版本：0.8.0 独立分享版；Windows／Steam；实验性项目。** 只支持你自己开房，或有权限安装服务端模组的环境。目前只适配温蒂及阿比盖尔。没有独立登录的第二个 Steam／Klei 账号，不需要占用玩家的键盘鼠标。

这是可供朋友独立安装的源码包，使用安装者自己的 Codex 登录。**不包含作者的 QQ 程序、私人角色、聊天、记忆、存档和认证，也没有一键配置 QQ 的功能。** QQ 互通属于原型的单独接入层；本仓库保留经过鉴权的本机接口，供以后自行适配，不会自动读取你的 QQ。

## 能做什么

| 功能 | 当前行为 |
| --- | --- |
| 原版人物机制 | 生命、饥饿、理智、温度、潮湿、背包、工具、装备耐久、配方和真实动作；按原版成本执行 |
| 日常工作 | 地表采集、农务、普通植物移植、中间材料制作、基础烹饪、存取和整理物资、基础自卫 |
| 跟随与远程控制 | F10／屏幕按钮；跟随帮忙、待命、回基地、继续／取消任务、同分片地表集合传送 |
| 温蒂能力 | 阿比盖尔召唤和收回；其余已适配的安全判断由同伴处理 |
| 任务连续性 | 目标、步骤、实际计数、暂停原因和检查点保存；临时避险后继续原目标，受阻时可调整做法 |
| 长期规划 | 生存指南、眼前／中期／长期目标板、已知资源地点、长期照料项目和行动结果日志 |
| 仓储与材料 | 按缺额拆堆取料，尽量保留样品；查附近已观察箱子中的同类物品；缺空间时尝试按真实配方做箱子 |
| 交流与历史 | 缺料吐槽、具体求助、分享打算；主动发言有冷却且允许沉默；左下角历史窗显示完整内容并可滚动，支持自动／手动黑白字 |
| 记忆与日记 | 当前世界记录写入游戏存档及本地文件；自愿写日记，无每日条数上限 |

### 尚未完整适配

烧林制炭、主动刷蜘蛛巢、洞穴跨分片迁移、海上／海钓、骑牛、Boss 专项、小幽灵完整任务链、阵营技能以及第三方模组专属界面。模组注册标准配方或组件，不代表全部专属操作都会自动学会。珍贵物资受保护，未知材料来源和不可执行步骤应明确求助。

模型会有延迟，也可能判断错误。一个目标被接收不等于已经完成；成功由游戏动作回执和实际状态确认。请先用测试世界验收，不要用重要存档试首次安装。

## 首次安装：四步

### 1. 准备游戏、Node 和模型登录

- Windows 版《饥荒联机版》，允许安装服务器模组。Steam → 游戏属性 → 已安装文件 → 浏览，可以找到游戏目录；该目录应包含 `data`、`bin64`、`mods`。
- 安装 [Node.js 22 或以上版本](https://nodejs.org/)，在新终端运行 `node --version`。
- 按 [Codex CLI 官方文档](https://developers.openai.com/codex/cli/)安装 CLI，使用你自己的账号执行 `codex login`，再用 `codex login status` 确认。认证方式见 [OpenAI 官方说明](https://developers.openai.com/codex/auth/)。
- 从本仓库 **Code → Download ZIP** 下载并解压，放在固定的可写目录。不要在 ZIP 压缩包内直接运行。

登录、可用模型、额度和计费以你自己的账号为准。ChatGPT 登录与 API 密钥是不同认证方式；本项目不提供账号，不承诺免费或无限额度，不要求你复制认证文件给朋友。普通使用无需安装本项目开发依赖；Node 和 Codex 需自行安装。

### 2. 安装模组

先保存并**完全退出游戏和专服**。双击 `安装.cmd`，按提示输入游戏目录；也可以在项目目录的终端运行：

```powershell
node tools/setup.mjs --game "D:\SteamLibrary\steamapps\common\Don't Starve Together"
```

上面的路径只是示例，换成你自己的。不要选 `mods` 子目录。安装会备份同名旧模组、复制本项目、生成本机随机令牌，并从通用示例创建自己的 `role.md`；不会提供或修改你的世界存档。

找不到 Codex 时指定实际文件：

```powershell
node tools/setup.mjs --game "你的游戏目录" --codex "你的Codex路径\codex.exe"
```

也支持官方 npm 包里的 `bin/codex.js`，不接受 `.cmd`／`.bat` 包装器。默认沿用 CLI 的模型；确有需要可加 `--model "你有权限使用的模型名"`。端口默认 `3131`，被占用时加 `--port 3132` 后重新配置。

### 3. 启动并进入测试世界

1. 双击 `启动.cmd`：启动本机 AI 桥接，并通过 Steam 打开游戏。
2. 在自建房的**服务器模组**中启用“AI 温蒂共玩”。默认需要加入者安装同一模组；先只用本模组建立基线。
3. 房主进入地表后自动绑定同伴。按 **F10** 或点“伙伴 F10”；没生成时点“加入伙伴”。快捷键冲突可在模组选项改 F9／F8。
4. 在基地说“家在这里”，或点“此处设基地”。再试“收集12根木头”“跟着我”“待命”“继续原任务”。

面板不会暂停世界。先熟悉快捷按钮，再观察自主行动。游戏内提问攻略、讨论规划不自动等同于让她开工。

### 4. 保存、退出与下次继续

正常使用游戏自己的保存退出。下次从同一项目目录启动，再进入原世界，任务与重要记忆按世界恢复。

只启动 AI：`node tools/start.mjs`。只停止桥接：双击 `停止AI.cmd`。停止桥接不会替你保存或关闭游戏。需要模型时，游戏和桥接进程都要保持运行；模型失败时本地快捷控制仍可使用。

## 规划、记忆和人设在哪里

| 位置 | 用途 | 可上传吗 |
| --- | --- | --- |
| `role.example.md` | 通用角色示例，无私人经历 | 可以 |
| `role.md` | 安装者自己的稳定人设，可改性格和语气 | 不要上传 |
| `bridge/survival-guide.md` | 长期生存目标知识，不能突破动作能力边界 | 可以 |
| 游戏原版存档 | 同伴、背包、家、任务、目标板和长期项目 | 不要上传 |
| `state/worlds/` | 按房主／世界／分片隔离的游戏问答、任务与经验 | 不要上传 |
| `state/actions/` | 去重保存的实际行动事件 | 不要上传 |
| `state/journals/`、`state/shared-game.json` | 当前或上次状态的本机镜像；离线不是实时状态 | 不要上传 |
| `state/diary.json` | 自愿日记，本独立版索引保留最近200条，无每日次数限制 | 不要上传 |
| `bridge/config.json`、已安装模组的 `ai_private.lua` | 你自己的本机连接令牌与配置 | 不要上传 |

稳定人设只说明人物与功能约定，玩法与执行事实放游戏知识／记忆。修改你自己的 `role.md` 即可改变口吻；不必把整份攻略塞进去。世界回滚时应以加载后的游戏存档为准，旧日记不能证明建筑或物品仍存在。

稳定期约20秒检查一次规划，重要结果可在最短5秒间隔后触发下一次判断；同时仅一个模型请求。模型可能花数十秒返回，这些间隔不是响应速度保证。等待期间继续有效动作与紧急生存；方法修订保留根目标与实际进度。

## 常见问题

- **F10没反应：** 确认启用的是服务器模组、房主已进入地表、同伴已生成；检查热键冲突以及桥接是否启动。
- **AI连接失败：** 先运行 `codex login status`，再看本机 `state/service.stderr.log`；确认 CLI 路径、模型可用性和网络。反馈时只摘取脱敏错误，不上传整个日志目录。
- **3131端口被占：** 安装时改用其他端口，本项目启动器与模组必须使用同一份生成配置。不要开放公网端口。
- **朋友加入游戏：** 由房主运行桥接及其模型登录，不把房主令牌、认证或私人记忆发给朋友。单独开世界的朋友需要自己安装和登录。
- **历史窗能拖动吗：** 这一版固定在左下角，避免鼠标移动冲突；支持滚动、收起和配色，暂不提供拖动。
- **换目录／升级：** 停止本项目桥接，保存并退出游戏；保留自己的私密配置、角色和 `state` 后更新源码，再运行安装配置。不要把自己的数据重新打包给别人。
- **支持其他人物或所有模组吗：** 目前只适配温蒂；可参考开发资料新增执行器。模型知道攻略不能代替游戏接口实现。

## 开发、测试与贡献

```powershell
npm.cmd ci --ignore-scripts
npm.cmd test
npm.cmd run check
npm.cmd run audit
```

默认测试使用虚构数据／模拟 CLI，不调用真实模型，也不启动游戏。完整参考脚本回归需从你自己安装的游戏导入：

```powershell
powershell -NoProfile -File tools/import-reference.ps1 -GamePath "你的游戏目录"
npm.cmd run test:all
node tools/check-ui-api.mjs
```

`reference/`仅本机测试使用，不发布游戏代码。实际验证记录见[验证说明](docs/release-verification.md)，人工测试步骤见[测试清单](docs/testing-checklist.md)。分享版自己的检查与原型的实机结果分开记录，不能把原型通过数当成朋友电脑验收。
